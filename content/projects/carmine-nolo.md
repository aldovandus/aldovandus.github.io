## Overview

Applicazione mobile per la gestione delle prenotazioni di Carmine Nolo, con un'base utenti attiva e flussi operativi ottimizzati per gestire il volume giornaliero di appuntamenti.

## Il problema

Con ~15 appuntamenti al giorno e una crescita rapida degli utenti, il sistema doveva gestire il sovraffollamento delle prenotazioni e garantire un'esperienza fluida su mobile, con comunicazioni automatizzate.

## Soluzione

App React Native con Tamagui per UI nativa performante, Supabase per backend e auth, Zustand per stato locale. Sistema di priorità premium per gestire picchi di domanda. Email automatizzate per conferme e promemoria.

## Risultati

- **800+ utenti registrati**
- **~15 appuntamenti/giorno** gestiti in autonomia
- Sistema priorità premium per picchi di prenotazioni
- UX mobile nativa ottimizzata

## Overview

Mobile application for Carmine Nolo booking management, with an active user base and optimized operational flows to handle daily appointment volume.

## The problem

With ~15 appointments per day and rapid user growth, the system needed to handle booking overcrowding and ensure a smooth mobile experience with automated communications.

## Solution

React Native app with Tamagui for performant native UI, Supabase for backend and auth, Zustand for local state. Premium priority system to manage demand peaks. Automated emails for confirmations and reminders.

## Results

- **800+ registered users**
- **~15 appointments/day** managed autonomously
- Premium priority system for booking peaks
- Optimized native mobile UX
