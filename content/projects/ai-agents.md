## Overview

Progetto personale di ricerca e sviluppo su agenti AI e strumenti di produttività per developer, integrati nel workflow quotidiano di sviluppo software.

## Il problema

Lo sviluppo software moderno richiede velocità senza compromettere qualità. Task ripetitivi — refactoring, setup, documentazione, review — consumano tempo che potrebbe essere dedicato a problemi di business.

## Soluzione

Sperimentazione con agenti multi-agent orchestrati via Claude Code e Cursor, MCP server per integrazioni con tool esterni, e context engineering per migliorare la qualità del codice generato. Workflow documentati e replicabili per team.

## Risultati

- Workflow multi-agent operativi per task di sviluppo ricorrenti
- MCP server custom per integrazioni avanzate
- Riduzione significativa del tempo su refactoring e setup
- Transizione attiva verso AI Application Engineer
